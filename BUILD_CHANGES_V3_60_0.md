# V3.60.0 — чем выше уровень, тем легче её уговорить

- Лестница «насколько она поддаётся уговорам» для каждого из 8 этапов (`OPENNESS_LADDER` в relationship_engine): на 1-м дразнит и говорит «рано», на 3-м после уговоров соглашается на горячую переписку, с 4-го это происходит «сейчас», а не «в фантазиях», на 6-м ведёт сама.
- Пошлый режим больше не велит подавать всё «через фантазии» — глубину решает уровень.
- Неизменно: только взрослые, только взаимное желание, без анатомической графики.
- Инициатива по уровням (`INITIATIVE_LADDER`): с 4-го уровня она сама начинает горячее, с 5-го ведёт — ему не нужно выпрашивать.
