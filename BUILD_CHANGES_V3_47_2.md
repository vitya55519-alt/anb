# AnnaBot V3.47.1–V3.47.2 — арт достижений, медиа-пул утра/вечера, безлимит 24 часа

Этот файл покрывает два неподеплоенных инкремента после V3.47.0.

## V3.47.1 — админский арт для достижений/миссий + клики в чате
- новая таблица `achievement_badges` (байты в PostgreSQL — переживает редеплой Railway);
- админка → «🏆 Арт достижений/миссий»: на каждую веху ставится одна картинка
  (`admin:badge:set:<key>` → прислать фото → сохраняется), есть «убрать арт»;
- при разблокировке achievement бот шлёт фото-открытку с подписью, а не только текст;
- доска достижений: Mini App показывает превью арта, в боте — кнопка «🖼» для раскрытия;
- исправление регрессии галереи V3.47.0: плитки снова открывают лайтбокс (`data-lb`);
- задания в чате: у всех 16 активных миссий появились рабочие CTA + постоянная
  навигационная строка (Чат / Галерея / Наедине / Premium / Создать);
- «📥 Сохранить» в галерее для десктопа: бот постит фото в чат пользователя —
  оттуда его можно переслать другу (на десктопе web-share не работает).

## V3.47.2 — медиа-пул для утренних/вечерних сообщений + безлимит 24 часа
- новая таблица `proactive_photos`: владелец загружает ~20 медиа в общий пул
  (Админка → «📸 Медиа для утра/вечера» → «➕ Добавить фото / GIF / видео»);
- V3.47.3-правки по запросу владельца: пул принимает не только фото, но и
  **GIF и видео** — у записи есть `kind` (photo/gif/video), лимиты 8 MB для
  фото и 20 MB для gif/видео, кнопки удаления размечены 📸/🎞/🎬;
- scheduler `_rituals`: утреннее/вечернее проактивное сообщение выбирает
  случайную запись пула и отправляет её через send_photo / send_animation /
  send_video с текстом как подписью — выглядит как реальное сообщение от неё;
  пустой пул = прежнее поведение (чистый текст); без водяных знаков;
- безлимитный текст для новых пользователей: первые `NEW_USER_UNLIMITED_HOURS`
  (по умолчанию 24) после регистрации лимт бесплатных сообщений не действует
  (текст — фото/видео по-прежнему по правилам);
- Mini App: в табе «Чаты» баннер «✨ Безлимитные сообщения — осталось HH:MM:SS»
  с живым обратным отсчётом (секунды из `/webapp/api/me`, тик каждую секунду,
  авто-скрытие по истечении окна);
- BOT_USERNAME по умолчанию теперь `Anna67901_bot`.
