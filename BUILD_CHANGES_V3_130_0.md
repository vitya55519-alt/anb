# V3.130.0 — «Начать чат» сразу под именем + без третьей руки на селфи

- Страница девушки в приложении: кнопка «Начать чат» (и «Истории») стоит сразу под именем, возрастом и «доступна». Уровень близости, галерея, путь, семейное положение, сюжеты и описание теперь ниже. Владелец: «чтобы было максимально просто».
- Фото: в правило рук (HANDS_RULE) добавлено, что при обычном селфи телефон и есть камера и в кадре его не видно. Тянущаяся к зрителю рука и есть рука с телефоном, а телефон в руке бывает только в отражении зеркала. Скрин владельца: селфи на набережной с жестом «тсс», телефон в руке плюс вытянутая рука, итого три руки.
