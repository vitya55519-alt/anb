# V3.56.7 — Медиа-пул «утра/вечера» теперь принадлежит героиням

## Симптом (фидбек владельца)
В чате Нади (конструкторная персона) пришло фото совершенно другой девушки:
«1,2 фото норм модель, а 3 фото вообще это кто?». Первые два — свежие рендеры
«Наедине» (референсы работают, лицо её). Третье — кадр из общего пула
`ProactivePhoto`, прилетевший проактивно.

## Корень
Таблица пула медиа (V3.47.2) не имела привязки к персонажу:
`random_proactive_photo()` брала случайный кадр из ВСЕГО пула. Утренний/вечерний
ритуал, «Подарок от неё» и «Жизнь без тебя» подставляли лицо любой героини в
чат к любой другой. V3.51.1 так же лечила только бонус-фото задания — это
остальные три рельсы.

## Исправление
- `models/app_models.py`: `ProactivePhoto.character_id` (nullable, индекс) —
  авто-миграция `services/db.py` добавит колонку на старте. `NULL` = старый
  нетегнутый кадр: НЕ отправляется, владелец перетегает или удаляет.
- `services/retention_features_service.py`:
  `random_proactive_photo(character_id)` — строгий выбор только её кадров
  (пустой пул → текст без фото); `add_proactive_photo(..., character_id)`;
  `set_proactive_photo_character(id, char)`; `list` отдаёт `character_id`.
- Рельсы: ритуал берёт `selected_character` пользователя (заодно текст ритуала
  теперь тоже про её героиню, а не глобальный `CHARACTER_ID`), подарок —
  `user.selected_character` (+ аудит-лента пишет настоящую героиню),
  life-события — своего персонажа.
- `main.py`, админ-экран «📸 Медиа для утра/вечера»:
  - «➕ Добавить» → клавиатура «Чьё это фото?» (все карточки, включая
    конструкторные) → пришлённый медиафайл сохраняется на неё;
  - каждая кнопка кадра помечена именем героини (`🗑 📸 #3 Ася`), `❓` — нетег;
  - кнопка `🏷 #N` — перетеить кадр;
  - `/cancel` чистит оба ожидания.

## Тесты
- `tests/test_v3567_pool_isolation_static.py` (+6): колонка в модели, строгий
  пик + ре-тег в сервисе, все три рельсы передают персонажа, админ-флоу
  связывает загрузку с героиней.
- Пинов правки: `test_v3472_media_pool_static.py` (сигнатура add, пик с
  `char_id`, вызов upload), `test_v3560_spicy_money_premium_static.py`
  (подарок — `random_proactive_photo(gift_char)`).
- Полный прогон: 16 failed / 1076 passed / 1 error — baseline parity.

## После деплоя (действие владельца)
Старые кадры пула без героини не рассылаются, пока не перетеганы:
Админка → «📸 Медиа для утра/вечера» → `🏷 #N` → героиня.
