# V3.55.3 — Третья вкладка «⭐ Премиум» на «Персонажах» (замена секции V3.55.2)

## Постановка (владелец, голосом + скриншот)
На странице «Персонажи» было два сегмента: «🍑 Персиковый сад» (официальный ростер)
и «👥 Сообщество» (персонажи из конструктора). Владелец просит **три вкладки**:
добавить «⭐ Премиум-персонажи». Для пользователя **без Premium вкладка закрыта**
(тап не переключает — тост «Доступно с Premium ⭐» и увод в магазин). Внутри
механика как в «Сообществе»: сетка + кнопка добавить персонажа, но только для
премиум-персонажей. Добавляет их **только владелец** через тот же конструктор
(фото персонажей он подложит сам). Премиум-персонажи должны визуально отличаться.

## Ключевая находка: новый столбец НЕ нужен
`CharacterCard.status` уже поддерживает значение `'premium'` (STATUS_LABELS в
`services/character_card_service.py`), его ставит админ-панель
(`admin:card:status:`) и на него уже завязаны ВСЕ существующие гейты:
бот-онбординг (`main.py` ~1994), просмотр карточки (~2104), SPA-гейты
(`doSelect` / `openCharPage` / `openCharacter`). Мария уже `status='premium'`.
Поэтому премиум-персонаж = карточка со статусом `premium`, хоть встроенная, хоть
конструкторная.

## SPA (`webapp/index.html`)
- Третий сегмент-кнопка `data-seg="prem"` в `#charSeg`; подпись из нового i18n
  `seg_premium` («⭐ Премиум» и т.д.) во всех 7 локалях.
- Обработчик сегментов: тап по `prem` без `ME.premium` НЕ переключает вкладку —
  `toast(L.need_premium); showTab('shop')`.
- `renderCharacters` разводит три корзины: `prem` — только `status==='premium'`;
  `official` — без custom и без premium; `community` — custom, но premium
  исключён (персонаж не едет на двух вкладках сразу). Поиск по витрине теперь
  доступен и на `prem`.
- Пагинация идёт по всему видимому списку `shown` (ветка `regular` из V3.55.2
  убрана вместе с секцией `#premSec`).
- Вкладка `⭐` приглушается для беспрема (CSS `#charSeg button.lockedseg`,
  вешается по `!(ME && ME.premium)`).
- Кнопка ➕ создания: на `community` осталась всегда; на `prem` своя ➕ показывается
  **только админу** (`ME.admin`) и открывает мастер с флагом премиума
  (`openWizard(true)` → `WIZ.premium` → тело `draft` несёт `premium`). Обычные
  пользователи не видят ➕ на премиум-вкладке.
- `showCommunitySeg()` → `segForCreate(isPremium)`: после создания персонаж
  уводит на `prem`, если флаг был, иначе на `community`.

## Бэкенд (`main.py`)
- `_custom_premium_gate_block(character_id, telegram_id)` — читает статус карточки
  и закрывает её для чужого беспрема; пропускают: Premium-пользователь, админ и
  **автор** собственной персонажи (`webapp_service._mine_character_ids`).
- Обе точки входа приложения чинят обход веткой custom (раньше только проверяли
  существование): `_webapp_api_chat_send` и `_webapp_api_chat_media` теперь зовут
  гейт в custom-ветке и отдают тот же `premium_required` 403 (SPA уже мапит его в
  paywall-тост + магазин).
- `_webapp_api_constructor_draft`: флаг `premium` пишется в сессию **только если
  `telegram_id in ADMIN_TELEGRAM_IDS`** — подделанный флаг из тела ничего не даёт.
- `_finish_constructor`: карточка регистрируется со `status='premium'`, когда
  админ-флаг стоит, иначе обычный `'active'`. Модерация/публикация
  (`charmod:approve`) трогает только `is_visible`, статус сохраняется.
