# AnnaBot V3.47.4 — своя карусель на странице персонажа (только витрина)

Запрос владельца: «только визуал, картинки разные ставить и все» — менять
фото карусели страницы персонажа, НЕ трогая каноны, из которых генерируются фото.

## Что нового
- новая таблица `page_gallery_shots` (байты в PostgreSQL — переживает редеплой);
- Админка → Персонажи → карточка → «🎠 Карусель страницы»:
  - «➕ Добавить фото» — можно присылать несколько подряд, каждое встанет
    следующим слайдом (до 8 MB, максимум 6 слайдов на персонажа);
  - «🗑 1…6» — удалить слайд, «🧹 Очистить всё» — вернуть канонические фото;
  - `/cancel` — закончить загрузку;
- публичный роут `GET /webapp/pgal/{character_id}/{shot_id}` — URL несёт id
  строки, поэтому замена видна мгновенно и не требует деплоя;
- payload витрины: если у персонажа есть свои фото — карусель страницы берёт
  их; если нет — прежние канонические снимки (`character_gallery()`);
- сводка карточки в админке показывает «Карусель страницы: N фото» и прямо
  говорит, что на генерацию это не влияет.

## Гарантии
- генерация фото не читает `page_gallery_shots` вообще — каноны и DNA-профили
  остались единственным источником внешности (тест
  `test_canonical_references_not_replaced`);
- сетка витрины (одна карточка-плитка) по-прежнему управляется «📥 Медиа
  витрины» — новый экран отвечает только за карусель страницы.
