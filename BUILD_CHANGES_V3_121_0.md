# V3.121.0 — один ритуал на героиню в день

Владелец: «всем идёт одно голосовое, русскоязычным русское, англ английское, фото тоже всем одинаковое, либо я разорюсь».

- Утренний и вечерний ритуал собирается один раз на (героиня, язык, день): одна фраза, одно голосовое (один вызов TTS), одно фото. Всем пользователям этой героини уходит одно и то же.
- Персональные тексты через LLM (morning_callback) в ритуалах больше не вызываются, когда включён общий режим.
- Фото общее и «чистое» (без белья), потому что одно и то же уходит и тем, кто не подтвердил 18+.
- Тестовый показ админу собирает этот же набор, так что пользователи получают ровно то, что одобрено.
- Английская утренняя фраза (EN_MORNING).
- Флаг `RITUAL_SHARED` (по умолчанию вкл). `RITUAL_SHARED=false` возвращает персональные ритуалы.
