# V3.117.0 — бенгальский интерфейс, она говорит на его языке

- В приложении новый язык интерфейса «বাংলা» (настройки → язык, нижнее меню, главные экраны, магазин, звонок). Telegram с языком bn открывает приложение сразу по-бенгальски.
- Героиня отвечает на языке, на котором он пишет: бенгальский (и латиницей «Banglish»), хинди, испанский, итальянский, французский, португальский, немецкий, китайский, японский, корейский, арабский, тайский, английский. Раньше понимала только RU/EN, на остальное отвечала по-русски.
- Порядок: язык его сообщения → его последние сообщения → язык, выбранный в приложении → язык Telegram. Кириллица всегда = русский, так что русские чаты не меняются (RU purity как была).
- Если ответ вышел не на том языке — одна перегенерация (как для английского раньше).
- Выбор языка в приложении сохраняется на сервере (`users.chat_lang`, авто-миграция), меню бота: русский для «Русский», английский для остальных.
- Её первые сообщения (утро/вечер, «скучаю», после оплаты) и первая сцена в чате приложения — тоже на его языке.
- Голос: Gemini TTS получает «she speaks <язык> natively»; запасной edge-tts — родные голоса (bn-IN, es-ES, ja-JP…). Живой звонок говорит на его языке.
- Оплата: испанский/японский/бенгальский интерфейс раньше получал русский магазин в рублях с СБП первым. Теперь любой нерусский интерфейс = английский магазин, доллары, Stars первыми, затем крипта.
