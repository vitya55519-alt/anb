# V3.55.2 — Секция «Премиум-персонажи» на вкладке «Персонажи»

> **Заменено в V3.55.3.** Владелец уточнил задачу (голосом + скриншот): вместо
> секции под сеткой — **третья вкладка-сегмент** «⭐ Премиум» рядом с
> «🍑 Персиковый сад» и «👥 Сообщество». Вкладка закрыта для беспрема, а
> премиум-персонажей добавляет только владелец через тот же конструктор.
> Секция `#premSec` удалена; код-история ниже оставлена для справки.

## Что изменено
Решение владельца: **модель доступа не меняется** (премиум-персонажи
открываются подпиской Premium, разовой покупки нет), но на вкладке
«Персонажи» они больше не мешаются в общем списке — под сеткой рендерится
отдельная секция «⭐ Премиум-персонажи» с подзаголовком:
- не-прему: «Открываются подпиской Premium» (тап → прежний paywall-тост и
  увод в магазин);
- премиуму: «Открыты твоей подпиской».

Сейчас в секции одна Maria; все будущие карточки со статусом `premium`
попадают туда автоматически.

## Изменения по файлам (только фронт)
- **webapp/index.html**:
  - `renderCharacters` делит отфильтрованный список: `premGirls`
    (официальный сегмент, `status==='premium'`) и `regular`; пагинация
    6/страница ходит только по `regular`;
  - билдер карточки вынесен в `cardHTML` и переиспользуется сеткой и
    секцией — одна разметка, один путь через `esc()`;
  - новый контейнер `#premSec` под `#charPager` + CSS `.premsec/.premhead/
    .premrow` (та же двухколоночная сетка, что и у `#chargrid`);
  - секция получает те же обработчики тапа (`openCharPage`) и тот же
    IntersectionObserver-«пинок» живых видео; при пустом списке скрывается;
  - в community-сегменте и при поиске секция не показывается (фильтр по
    `CHAR_SEG === 'official'`);
  - 3 i18n-ключа (`prem_chars_title/hint/owned`) во всех 7 локалях.
- **tests/test_v3482_grid_pagination_static.py**: пины среза/билдера
  обновлены на `regular`/`cardHTML`.

## Что НЕ менялось
- Бэкенд: `/webapp/api/characters`, гейты `premium_required` в чате/медиа,
  витрина бота — без правок.
- Разовая покупка персонажа — сознательно вне скоупа (выбор владельца).
