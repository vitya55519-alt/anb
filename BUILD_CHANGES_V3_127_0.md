# V3.127.0 — описание бота: много ИИ девушек и слова для поиска

- Описание и короткое описание (RU и EN) теперь про девушек во множественном числе
  и с поисковыми словами: «ИИ девушки», «чат с ИИ девушкой», «бесплатно».
- `BOT_DESCRIPTIONS_ENABLED=1` на Railway записывает только описания (имя задают
  `BOT_NAME_DEFAULT/RU/EN`); `BOT_PROFILE_ENABLED=1` работает как раньше.
