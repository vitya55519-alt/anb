# V3.111.0 — витрина первого часа, честный оффер после 150 сообщений, оплата для иностранцев

## Витрина первого часа
- Первое предложение (first_offer) приходит раньше: после 2 сообщений (было 3) и 8 минут паузы (было 20). Все 3 оплаты были в первые 4–95 минут после 1–4 сообщений.
- В первые 3 часа после /start (FIRST_HOUR_SHOWCASE_HOURS) сначала её короткое голосовое, потом размытое фото с ценой пробного прямо в подписи и кнопками оплаты в один тап (RU: 99 ₽ картой/СБП, затем Stars; EN: Stars, затем крипта/карта) + «все варианты».
- После оплаты Premium она присылает то самое фото, которое было размыто на карточке, без размытия (один раз). Событие showcase_photo_delivered.
- Флаг: FIRST_HOUR_SHOWCASE_ENABLED. Событие first_offer_sent теперь с metadata showcase/trial.

## Честный оффер после 150 сообщений (services/heavy_offer.py)
- Один раз в жизни, тем, кто написал 150+ сообщений (HEAVY_OFFER_MIN_MESSAGES), ни разу не покупал Premium и был активен за 3 дня. Только днём по Москве.
- Текст: что даёт Premium и что «если не хочешь, ничего не поменяется». Без таймеров, дефицита и вины.
- Флаг HEAVY_OFFER_ENABLED, события heavy_offer_sent / heavy_offer_sent_ok.

## Оплата для иностранцев в чате бота
- Раньше у EN-пользователя в чате бота вся клавиатура Premium была по-русски, а строки карты/крипты скрыты: платить можно было только Stars.
- Теперь: английская клавиатура Premium (Stars + «💎 crypto / card» через страницу Platega), английская стена «уснула» (демо, VIP, пробный), английские счёта Stars и сообщение со ссылкой Platega.
- Mini App уже показывал EN-пользователям Stars + крипту, не менялся.
