# AnnaBot V3.43.5 — обход приложения владельцем: четыре пункта

Запрос владельца: прошёл приложение по экранам (5 скриншотов) и собрал
четыре замечания. Все четыре закрыты в этом релизе.

## 1. Кнопка «Персики» — без глагола
- На welcome-клавиатуре и в главном меню кнопка фотокредитов теперь просто
  «🍑 Персики» / «🍑 Peaches» (было «Добавить персиков»);
- скриншот владельца показывал «Добавить клубничек» — это закешированная
  старая клавиатура Telegram, живой код давно был на персиках; новый
  лейбл ещё короче;
- нажатие по-прежнему маршрутизируется через `kb_pair('credits')`.

## 2. Картинки: стиль — картинкой, не эмодзи
- Выбор стиля (Аниме / Реализм / Фэнтези) был `<select>` с эмодзи
  🍑/📷/🐉, которые не читаются как «стили»;
- теперь три плитки `.styleTile` с нарисованными SVG-иконками: лицо в
  аниме-стиле, фотоаппарат, волшебная палочка со звёздами — разница
  видна глазами;
- выбранная плитка подсвечивается, выбор уходит в генерацию как
  `style: PIC_STYLE`.

## 3. Настройки внутри приложения: «пошлый режим» + язык интерфейса
- Переключатель «🌶 Пошлый режим» был спрятан только в чате бота — сам
  владелец его «еле нашел». Теперь в профиле приложения есть секция
  «Настройки» со строкой-тумблером;
- тумблер ходит через новый эндпоинт `POST /webapp/api/spicy`
  (Telegram-авторизация по init_data, 401 без неё; включение требует
  Premium — 403 `premium_required`, как и в ботовском `toggle:spicy`;
  выключение всегда разрешено), `api_me` отдаёт `spicy_mode`;
- там же выбор языка интерфейса: русский, английский, испанский,
  итальянский, французский, китайский, японский — семь чипов в
  настройках, выбор пишется в `localStorage` и перезагружает UI;
  язык из настроек бьёт язык Telegram-аккаунта;
- непереведённый хвост словаря падает на английский (не на русский) —
  миланский пользователь не видит кириллицу; нижняя навигация
  (`Персонажи/Чаты/Картинки/Магазин/Профиль`) переведена на все семь.

## 4. Фигура больше не «скачет» (Эмили)
- Владелец показал: в карточке у Эмили одна фигура, в генерациях — то
  большая грудь, то маленькая;
- причина: декларация фигуры и канонические референсы тянули промпт в
  разные стороны, и референс с меньшей грудью побеждал;
- строка `BODY IDENTITY` теперь явно объявляет, что декларированная
  фигура — постоянный признак и OVERRIDES референсы: «даже если на
  референсе грудь меньше/плосче или телосложение другое — рендери ровно
  заданную фигуру», запрет на уменьшение/увеличение груди и расширение
  талии/бёдер в каждом кадре.

## Что НЕ менялось
- Правило Premium для включения пошлого режима (и в боте, и в приложении
  — одинаково), сам контент пошлого режима;
- гейты сцен по стадиям, 18+-подтверждение, coverage-строки;
- BODY_SPECS дом-архетипа из V3.43.3 — усиливается только формулировка
  приоритета.
