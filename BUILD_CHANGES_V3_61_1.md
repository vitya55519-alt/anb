# V3.61.1 — шаблоны конструктора и старт «С сюжетом / Без сюжета»

- Конструктор: 6 готовых шаблонов сверху (Строгая начальница, Медсестра, Соседка по квартире, Две сестры (аниме, дуэт), Бывшая, Аниме: доктор). Тап заполняет все поля и имя, дальше можно править.
- Конструктор: новое необязательное поле «Первая сцена» (группа «История»).
- Первое открытие пустого чата показывает выбор «С сюжетом» / «Без сюжета».
  - С сюжетом: она начинает со сцены (*действие* + первая реплика). Своя сцена из конструктора, для встроенных девушек готовые сцены (`OPENING_SCENES`), иначе сцену пишет модель по описанию персонажа.
  - Без сюжета: чат пустой, пользователь пишет первым.
- API: `POST /webapp/api/chat/start {character_id, mode}`; options API отдаёт `templates`.
- Все персонажи и сцены взрослые.
